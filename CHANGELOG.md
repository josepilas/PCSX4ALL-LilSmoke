# 0.0.1

- First public PCSX4ALL-LilSmoke source and bundled LilSmoke Application.
- Native MIPS dynarec, Unai software graphics and SPU audio.
- Standalone game browser and PSX Open Core integration.
- Start+X menu; Start+Select exit; no analog-stick mouse cursor.
- Ten save-state slots with transactional writes, damaged-state recovery,
  old-kernel sync fallbacks, and explicit storage error reporting.
- Public input support and independently rewritten PCSX platform bridge.
- Complete corresponding dependency sources, build recipes and mixed-license notices.
- Validated under one-CPU Linux/MIPS with 120 MiB RAM, including real SPU PCM,
  production menu save/load and storage-fault regression tests.
- No commercial game data, BIOS, stock firmware, or private OS image included.

This is a new public-source build. Full physical performance testing of this
exact release remains separate from VM functional qualification.
